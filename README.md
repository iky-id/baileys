WhatsApp Bot merupakan bot otomatis berbasis Node.js yang menggunakan library Baileys untuk menghubungkan bot dengan WhatsApp.

✨ Features

- ⚡ Fast Response
- 📱 Multi Device Support
- 🔑 Pairing Code & QR Code
- 🔄 Auto Reconnect
- 🛠️ Easy Customization
- 📂 Modular Plugin System
- 🚀 Lightweight & Efficient

📦 Requirements

- Node.js
- NPM
- Koneksi Internet
- WhatsApp Account

🚀 Installation

Clone repository:

git clone https://github.com/iky-id/baileys.git

Masuk ke folder:

cd baileys

Install dependencies:

npm install

Jalankan bot:

npm start

📁 Project Structure

```text
baileys/
├── index.js
├── package.json
├── config.js
├── database/
├── lib/
├── plugins/
└── sessions/
```
